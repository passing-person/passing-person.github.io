# Project Cat Demo

[Play Demo](/Game/ProjectCatDemo/)

This is a small playable demo for the current game jam prototype.

The goal is simple:

**Annoy the supervisor, make them angry, then escape.**

## What to Do

1. Go to the supervisor.
2. Press `E` to meow.
3. Jump onto the keyboard.
4. Hold `Left Click` and mash `Space` to disturb the keyboard.
5. When the keyboard is locked, move to the phone.
6. Disturb the phone the same way.
7. When the supervisor becomes fully angry, run back to the door and escape.

## Controls

| Input                     | Action                       |
| ------------------------- | ---------------------------- |
| `WASD`                    | Move                         |
| `Shift`                   | Sprint                       |
| `Mouse Movement`          | Rotate Camera                |
| `Space`                   | Jump / Mash while disturbing |
| `E`                       | Meow                         |
| `Q`                       | Act cute and reduce rage     |
| `Left Click Hold + Space` | Disturb keyboard or phone    |

## Notes

The supervisor gets angrier as you disturb objects.

At maximum rage, the supervisor will chase you while smashing obstacles out of the way.

Run to the door before getting caught.
