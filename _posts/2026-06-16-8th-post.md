# Playable Demo

[Play Demo](/Game/ProjectCat/)

## Controls

| Input                      | Action              |
| -------------------------- | ------------------- |
| `WASD`                     | Move                |
| `Shift`                    | Sprint              |
| `Space`                    | Jump                |
| `Left Click`               | Attack              |
| `Mouse Movement`           | Rotate Camera       |
| `Keyboard / Mouse Mashing` | Escape when grabbed |

## Goal

Break objects while avoiding the chaser.

Objects can be pushed, damaged, and destroyed by attacking them.

The chaser reacts to sight and sound.
If it sees you, it will chase you.
If it catches you, you cannot move or jump.

Mash the keyboard or mouse quickly to escape.
